# 🗳️ Fullstack Survey Application Kata

**Version: 1.0**

## 🌟 Context

Build a simple, functional fullstack MVP for a customer satisfaction survey application.

## 📋 Instructions

Develop a simplified MVP demonstrating basic survey functionalities, including backend-frontend integration. The backend should handle business logic, validation, data storage, and provide an API for the frontend to consume. This application will allow businesses to collect customer feedback through customizable surveys.

## 🚀 Challenge Details

### 📊 User Story 1: Satisfaction Survey

- Create a satisfaction survey page where customers can rate their experience on a scale from 0 to 10
- Display a question (e.g., "Would you recommend our service to others?")
- Show a rating scale with numbers from 0 to 10
- Visual indication of the selected rating
- Submit button to save the response
- Implement proper validation and error handling

### 💬 User Story 2: Feedback Form

- Create a feedback form where customers can leave detailed comments
- Include fields for first name, last name, email, and comment
- Implement form validation (required fields, email format)
- Save the feedback data to the backend
- Display a confirmation message after successful submission

## 🌟 Bonus Features (Optional)

- **Admin Dashboard**: View submitted surveys and feedback
- **Customizable Surveys**: Admin can create custom questions
- **Response Analytics**: Simple charts/graphs of survey results
- **Responsive Design**: Mobile-friendly implementation
